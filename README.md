# BluSafe-TechScanner

An open-source website technology and vulnerability scanner built to help developers, system administrators, and security researchers identify outdated software and known vulnerabilities.

---

## Features

- WordPress Core vulnerability scanning
- WordPress Plugin vulnerability scanning
- WordPress Theme vulnerability scanning
- OSV vulnerability scanning
- Latest version detection
- Secure authentication
- Session security
- Offline technology cache
- FastAPI backend support
- PostgreSQL scan logging

## Installation

1. Upload TechScanner.php
2. Open it in your browser.
3. Enter your Backend URL.
4. Enter your License Key.
5. Set an administrator password.
6. Refresh the technology list.
7. Start scanning.
